A commit is a domain commit when every changed file serves pages of one domain only and every allowlist entry it removes belongs to that domain's pass. Every other commit is a shared commit, and the second table lists the routes it affects and the entries it removes.

Route scope is read from the repository at the commit and its parent. MDX files serve their own page. Components, `lib` and `data` files serve the pages whose MDX or app page imports them, directly or through other files, and a file in `lib` or `data` used by several domains is scoped by the routes its changed lines name. Tests are scoped by the routes, content files and components they name. Markers: `unused` (a component no page imports), `tooling` (scripts and shared `lib` or `data` files), `evidence` (captures and brand-v2 records), `shared test` (a test that names no route), `every article` (the article page template).
