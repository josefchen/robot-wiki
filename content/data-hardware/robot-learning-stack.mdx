A robot-learning system turns recorded physical events into a trained policy, and the policy's decisions back into motion. The checkpoint is one part: LeRobot spans the whole stack, from motor middleware to dataset streaming and asynchronous inference <Cite id="lerobot-paper-2026" />.

<Image id="openvla-overview-2024" />

Machine learning systems pay heavy maintenance costs for data dependencies, configuration and hidden feedback loops <Cite id="hidden-technical-debt-2015" />. Treat the stack as seven contracts, each a handoff with a saved artifact and a test, and every failure traces to one boundary.

## Contract 1: record calibration with the hardware

Record firmware, control mode and calibrated transforms for every sensor: no later split can correct a camera move nobody recorded. Time offsets between sensors are calibration parameters too, estimable with the spatial ones <Cite id="kalibr-2013" />, and [calibration](/classical/calibration) covers the residuals.

<Image id="droid-camera-calibration-2024" />

## Contract 2: capture every episode, failures included

An episode, one recorded attempt at a task, holds raw observations, robot state, commanded action, measured response, outcome, interventions and timestamps. Keep the failures: RoboMIND releases 5,000 real failure demonstrations with annotated causes <Cite id="robomind-2024" />.

| Format or dataset | What it standardizes |
| --- | --- |
| MCAP | ROS 2 Iron's default recording format, replacing slower SQLite3 storage <Cite id="ros2-iron-mcap-2023" /> |
| RLDS | Lossless episode sharing <Cite id="rlds-2021" /> |
| DROID | [Collection hardware](/data-hardware/teleop-rigs) and protocols across institutions <Cite id="droid-2024" /> |
| <Term id="open-x-embodiment">Open X-Embodiment</Term> | Over a million trajectories from 22 embodiments <Cite id="open-x-embodiment-2023" /> |

## Contract 3: version every preprocessing step

Version every step from frame selection to splits. LeRobot builds its tools around one workflow <Cite id="lerobot-docs-2026" />; format 3.0 packs many episodes per file, since one file each hit file-system limits <Cite id="lerobot-dataset-v3-2025" />. Its November 2026 release streams from the Hugging Face Hub, then holding almost 300 TB of LeRobot data <Cite id="lerobot-v0-7-2026" />.

Arrays of equal width can hold different [action labels](/manipulation/action-spaces): joint targets, gripper deltas, torques. Per-dimension binning performs poorly on high-frequency dexterous data, so FAST+ is a universal tokenizer trained on 1M real trajectories <Cite id="pi0-fast-2025" />.

Split by the factor a claim generalizes across, since random splits leak near-identical scenes into testing. Across 15,000+ real rollouts, environment and object diversity mattered far more than demonstration count <Cite id="lin-data-scaling-laws-2024" />.

## Contract 4: a run saves everything needed to rerun it

A run saves its configuration, code revision, dataset hash, seeds and normalization statistics with its weights. Identical seeds can still diverge across PyTorch releases and between CPU and GPU <Cite id="pytorch-reproducibility-2026" />. Safetensors files store each tensor's type and shape in a header <Cite id="safetensors-format" />.

| Recipe | Result |
| --- | --- |
| robomimic | Recurrent behavior cloning strong where offline RL struggled on the same human demos <Cite id="robomimic-2021" /> |
| OpenVLA-OFT | OpenVLA <Cite id="openvla-2024" /> from 76.5% to 97.1% LIBERO success, 26 times the action throughput <Cite id="openvla-oft-2025" /> |
| RECAP | More than double the throughput on some of the hardest tasks <Cite id="pistar06-2025" /> |
| RACE | Picks checkpoints without robot trials, from action deviations on held-out successes <Cite id="race-checkpoint-selection-2026" /> |

## Contract 5: simulation must rank policies as hardware does

A simulated score is useful only if it ranks policies in the order hardware does. SIMPLER measures that agreement on matched tasks <Cite id="simpler-2024" />.

| Tool | Result |
| --- | --- |
| Isaac Lab | Large batches of environments <Cite id="isaac-lab-2025" />; 3.0 runs one task interface on several physics and rendering backends <Cite id="isaac-lab-3-0-2026" /> |
| PolaRiS | Rebuilds real scenes from short video scans; much stronger correlation with real results <Cite id="polaris-2025" /> |
| SimFoundry | Mean correlation of 0.911 across 7 tasks <Cite id="simfoundry-2026" /> |
| Sim and real co-training | Real-world task performance up 38% on average <Cite id="sim-real-cotraining-2025" /> |

## Contract 6: real-world results must state their conditions

Papers often report success rates without run counts, initial conditions or success criteria <Cite id="kress-gazit-evaluation-2024" />. LIBERO-Plus showed that modest perturbations expose gaps high scores hide <Cite id="libero-plus-2025" />; the [evaluation crisis](/data-hardware/evaluation-crisis) covers the statistics.

| Method | What it adds |
| --- | --- |
| RoboArena | Double-blind pairwise trials at several universities <Cite id="roboarena-2025" /> |
| AutoEval | Evaluation around the clock <Cite id="autoeval-2025" /> |
| RoboDojo | 42 simulated and 18 real-world tasks <Cite id="robodojo-2026" /> |
| Sequential testing | Stops early, cutting effort by up to 70% <Cite id="beyond-binary-success-2026" /> |

## Contract 7: a gate stands between policy and motors

On the robot the policy sits in a chain: observation assembler, model server, command gate, controller bridge and supervisor, with safety and fast feedback below. ROS 2 was redesigned from the ground up because ROS 1 lacked production-grade features <Cite id="ros2-science-robotics-2022" />. The [ROS 2 guide](/classical/ros2-for-ml-engineers) defines the interfaces, and ros2_control provides the real-time bridge <Cite id="ros2-control-docs-2026" />.

Real-time chunking computes the next action chunk while the current one runs <Cite id="real-time-chunking-2025" />, and SmolVLA decouples prediction from execution <Cite id="smolvla-2025" />. [Real-time execution](/manipulation/realtime-execution) has the latency budgets.

Export must preserve the numbers. The RAI Institute's Exploy packs a PyTorch policy's observation code, network and action processing into one ONNX file and checks numerical equivalence before hardware runs <Cite id="exploy-2026" />. A TensorRT engine works by default only with the TensorRT version that built it <Cite id="tensorrt-engine-compatibility-2026" />.

Also: ONNX graph versioning <Cite id="onnx-ir-spec" />, ONNX Runtime execution providers <Cite id="onnx-runtime-architecture" />, Intrinsic Core under Apache 2.0 <Cite id="intrinsic-core-2026" />, Qualcomm's PickNik deal <Cite id="qualcomm-picknik-2026" />.

## Failures go back into the dataset

A policy's own actions shape its future observations, which breaks the independence assumption of standard learning <Cite id="dagger-2011" />. Return each failure to the dataset tagged with its cause.

| Method | Result |
| --- | --- |
| Sirius | Weights samples by human trust; 27% higher real-hardware success <Cite id="sirius-2022" /> |
| CUPID | Under 33% of curated data yields state-of-the-art diffusion policies on RoboMimic <Cite id="cupid-2025" /> |
| LoopWAM | Three deploy-and-train rounds: 23.67% to 43.33% RoboChallenge success <Cite id="loopwam-2026" /> |
| Mulligan | 10 to 34 points higher on three real tasks, over 2,550 blinded episodes <Cite id="mulligan-2026" /> |

## A small team needs six pieces

Start with immutable versioned episode files, one versioned conversion command, a checkpoint registry and a deterministic offline test batch <Cite id="lerobot-dataset-v3-2025" /> <Cite id="hidden-technical-debt-2015" />. Add an evaluation sheet linked to episode IDs <Cite id="kress-gazit-evaluation-2024" /> and a policy process kept apart from the gate that approves its commands <Cite id="lerobot-paper-2026" /> <Cite id="safety-filter-2023" />.
