## Stage 1: frames and calibration come first

Learn [kinematics](/classical/kinematics/) first: which frame each pose is written in <Cite id="modern-robotics-2017" />. Sloppy notation "will inevitably lead to confusion and bugs" <Cite id="tedrake-manipulation-2026" />. A drifting camera transform makes a good policy look random, so [calibration](/classical/calibration/) and [state estimation](/classical/state-estimation/) come next <Cite id="kalibr-2013" />.

## Stage 2: data is a system

Each dataset step pairs synchronized observations, actions, state and task, which RLDS stores without loss <Cite id="rlds-2021" />. Replay ten episodes before scaling, checking timestamps, units and rotations. Past a threshold, variety beats volume <Cite id="lin-data-scaling-laws-2024" />.

| Public [datasets](/data-hardware/datasets/) | Scale |
| --- | --- |
| Open X-Embodiment | 22 robots from 21 institutions <Cite id="open-x-embodiment-2023" /> |
| DROID | 76k trajectories from 13 institutions <Cite id="droid-2024" /> |
| [LeRobot](/data-hardware/robot-learning-stack/) format, Hugging Face Hub | Almost 300 TB by November 2026 <Cite id="lerobot-v0-7-2026" />, with tools from motors to streaming <Cite id="lerobot-paper-2026" /> |

## Stage 3: a small imitation baseline comes before scale

[Behavior cloning](/manipulation/bc-foundations/) errors compound once the learner visits its own states <Cite id="dagger-2011" />; HG-DAgger fixes them with human takeovers <Cite id="hg-dagger-2019" />. Start with one camera and one task; robomimic found results sensitive to such design choices <Cite id="robomimic-2021" />. Then add ACT's action chunks <Cite id="act-aloha-2023" /> or Diffusion Policy's multiple modes <Cite id="diffusion-policy-2023" />.

## Stage 4: the action format is a contract

Joint positions belong to one mechanism; tool-pose changes carry across arms with compatible [action spaces](/manipulation/action-spaces/). Per-number action tokens handle fast data poorly <Cite id="pi0-fast-2025" />, and tool-space stiffness helped contact-rich RL <Cite id="martin-martin-2019" />. Change the format separately from the model.

## Stage 5: pretrained models cut the data you need

A [pretrained VLA](/manipulation/foundation-models/) pays off with language, new objects or many tasks. In TRI's blind trials, pretraining taught new tasks with a fraction of the data <Cite id="tri-lbm-2025" />. Five demonstrations per task lifted GR00T 2 from 40% to 95% on 50 new tasks <Cite id="gr00t-2-2026" />.

| Model | Why it matters |
| --- | --- |
| OpenVLA | Reproducible open recipe <Cite id="openvla-2024" /> |
| π0 | Over 10,000 hours of robot pretraining <Cite id="pi0-2024" /> |
| SmolVLA | Trains on one GPU, comparable to VLAs ten times larger <Cite id="smolvla-2025" /> |

## Stage 6: define success before the run

Fix success, failure, reset and timeout before the main run, and report trial counts and uncertainty, which papers often omit <Cite id="kress-gazit-evaluation-2024" />. STEP's sequential test needs up to 32% fewer trials <Cite id="optimal-stopping-2025" />. Measure latency: 100 ms nearly halved simulated success on moving targets <Cite id="vla-lagbench-2026" />.

Robot success under controlled changes is the measure. LIBERO-Plus perturbs LIBERO <Cite id="libero-2023" /> tasks in seven ways, such as viewpoint and lighting <Cite id="libero-plus-2025" />.

Also: SIMPLER's sim-to-real correlation <Cite id="simpler-2024" />; RoboArena's double-blind rankings <Cite id="roboarena-2025" />.

## Stage 7: RL needs rewards and resets

Domain randomization varies the simulation until reality looks like one more variation <Cite id="tobin-2017" />. Isaac Lab <Cite id="isaac-lab-2025" /> 3.0 separates tasks from physics engines <Cite id="isaac-lab-3-0-2026" />.

<Image id="robocasa-kitchens-2024" />

Online RL needs safe exploration, automatic resets and cheap evaluation, which SERL bundles <Cite id="serl-2024" />. Without them, use <Term id="imitation-learning">imitation learning</Term> or offline RL on logged data <Cite id="offline-rl-tutorial-2020" />. With them, real-arm [RL fine-tuning](/manipulation/rl-finetuning/) hit 100% on precise tasks in 1 to 2.5 hours <Cite id="hil-serl-2024" />.

Also: SimpleVLA-RL, 48.9% to 96.9% on LIBERO from one demonstration per task <Cite id="simplevla-rl-2025" />.

## The sequence: data, harness, baseline, then scale

Build replayable data, an evaluation harness and a behavior-cloning baseline. Add chunks, a pretrained VLA, then RL once reward and resets are real. Deploy on [ROS 2](/classical/ros2-for-ml-engineers/), which adds the production features ROS 1 lacked <Cite id="ros2-science-robotics-2022" />.
