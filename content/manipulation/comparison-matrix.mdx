## Narrow the field before comparing scores

Rule out models on weights, license and training data first; Gemini Robotics On-Device, for example, goes only to trusted testers via an SDK <Cite id="gemini-robotics-on-device-2025" />. Then drop those whose actions, speed, cameras or data needs do not fit the robot.

<Image id="roboarena-evaluation-2025" />

Compare the rest under one protocol, with identical cameras, horizon and resets, plus a behavior-cloning baseline. TRI's Large Behavior Model study used blind, randomized trials <Cite id="tri-lbm-2025" />. RoboArena's 600-plus double-blind pairwise episodes ranked seven generalist policies more accurately than centralized evaluation <Cite id="roboarena-2025" />.

## Actions are numbers, tokens or refined noise

A policy outputs plain numbers, word-like tokens, or noise refined into motion by diffusion or <Term id="flow-matching">flow matching</Term>. Training and running can differ: π0.5 learns from compressed FAST tokens <Cite id="pi0-fast-2025" /> but generates actions by flow matching <Cite id="pi05-2025" />.

The <Term id="predicted-horizon">predicted horizon</Term> is how many actions a chunk holds; the <Term id="committed-horizon">committed horizon</Term> is how many run before replanning. [Real-time chunking](/manipulation/realtime-execution/) computes the next chunk during the current one <Cite id="real-time-chunking-2025" />.

| Model | Predicted / executed actions |
| --- | --- |
| Diffusion Policy, simulated Push-T <Cite id="diffusion-policy-2023" /> | 16 / 8, from 2 frames |
| ACT <Cite id="act-aloha-2023" /> | 100, from its chunk-size tests |
| OpenVLA-OFT+, ALOHA <Cite id="openvla-oft-2025" /> | 25 / 25 at 25 Hz |
| π0.7 <Cite id="pi07-2026" /> | 50 / 15 or 25 |

## What each model builds on and controls

Backbone and conditioning are a model's pretrained parts and accepted inputs. Octo takes an instruction in words or a goal image <Cite id="octo-2024" />, and Skild says S1 performs a task shown in one video <Cite id="skild-s1-2026" />.

Cross-embodiment evidence comes in three strengths: many robots' training data, as in Open X-Embodiment's 22 robot types <Cite id="open-x-embodiment-2023" />; fine-tuning to a new body; one checkpoint running different bodies. CrossFormer has the strongest: identical weights control very different robots after 900,000 trajectories from 20 embodiments <Cite id="crossformer-2024" />.

Hierarchy separates planning from motion. π0.5 writes a subtask before acting, inside one model <Cite id="pi05-2025" />, and π0 can take subtasks from a separate vision-language model <Cite id="pi0-2024" />. GR00T N1.7's SONIC workflow hands latent action tokens to a separate whole-body controller <Cite id="isaac-gr00t-repo-2026" />.

Downloadable weights can still carry license limits: GR00T N1.7 pairs Apache 2.0 code with NVIDIA Open Model License weights <Cite id="isaac-gr00t-repo-2026" />. openpi lists π0, π0-FAST and π0.5 checkpoints <Cite id="openpi-repo-2024" />, and SmolVLA releases code, pretrained models and training data <Cite id="smolvla-2025" />.

## Seven rows carry caveats

| Row | Caveat |
| --- | --- |
| RT-1 <Cite id="rt1-2022" /> | "Limited" cross-embodiment: Kuka IIWA and Everyday Robots data, evaluated on Everyday Robots |
| ACT <Cite id="act-aloha-2023" /> | Task-specific, about 80M parameters, trained from scratch |
| RT-2 <Cite id="rt2-2023" /> | Excludes the chain-of-thought variant |
| OpenVLA <Cite id="openvla-2024" /> | 7B is the language model, beside a 600M visual encoder |
| OpenVLA-OFT <Cite id="openvla-oft-2025" /> | "Limited" means adapting a pretrained model to separate tasks and robot setups |
| GR00T N1.6 <Cite id="gr00t-n1-6-2025" /> | Actions relative to the current state for most bodies |
| π*0.6 <Cite id="pistar06-2025" /> | Recap training more than doubles throughput on some of the hardest tasks |

## Vendors leave out the details

| System | Gives | Leaves out |
| --- | --- | --- |
| Gemini Robotics 1.5 <Cite id="gemini-robotics-15-2025" />, 2 <Cite id="gemini-robotics-2-2026" />, 2.5 <Cite id="gemini-robotics-2-5-2026" /> | 1.5: continuous actions, one checkpoint for ALOHA, two-arm Franka and Apollo | Action head, chunk length, command rate, parameter count |
| Helix 02 <Cite id="helix-02-2026" /> | 200 Hz joint targets, 1 kHz actuator commands; the first Helix ran a 7 to 9 Hz onboard VLM over an 80M-parameter, 200 Hz controller trained by regression <Cite id="helix-2025" /> | Training loss, chunk horizon, release terms |
| AgiBot GO-2 <Cite id="agibot-go2-2026" /> | Slow planner, fast executor | Rates, backbone, output format, weight terms |
| Skild <Cite id="skild-series-c-2026" /> | A funding announcement | Reproducible evaluation, runtime details |

AgiBot's earlier GO-1 learned latent actions from over 1 million AgiBot World trajectories across 217 tasks <Cite id="agibot-world-2025" />. Generalist's 99% average success for GEN-1, against 64% for earlier models with 1 hour of robot data per task, is self-reported <Cite id="generalist-gen1-2026" />.
